# Jointbox — Advanced Features Roadmap

The next-generation roadmap across AI, automation, security, visibility, and
scale. This is forward-looking planning material, not a list of shipped
features. Status legend:

- **In Progress** — actively being built.
- **Planned** — committed, not yet started.
- **Research** — being evaluated; may change or be dropped.

---

## AI & Automation
*Operator assistance, recommendations, and network intelligence.*

| Feature | Status | Description |
|---|---|---|
| Intelligent assistant | Planned | Guided troubleshooting and contextual next-best actions for operators. |
| AI-powered network management | Planned | Predictive monitoring, anomaly detection, and proactive operations. |
| Personalized recommendations | Planned | Behavior-driven package, pricing, and support recommendations. |

## Operations & Visibility

| Feature | Status | Description |
|---|---|---|
| Real-time monitoring 2.0 | In Progress | Expanded live observability across subscriber, router, and segment health. |
| Customizable dashboards 2.0 | In Progress | Role-based, KPI-focused widgets for operators, managers, and resellers. |
| Mobile optimization 2.0 | Planned | A field-ready responsive experience for mobile operations. |
