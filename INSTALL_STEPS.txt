-------------------------------------------------------------------
 IF YOU JUST WANT IT DONE (ONE COMMAND)
-------------------------------------------------------------------
 Put the project folder on the machine, then:

     sudo bash "/opt/jointbox/deploy/install-ubuntu.sh"

 (or the GitHub one-liner:)

     curl -fsSL https://raw.githubusercontent.com/<YOU>/<REPO>/main/deploy/bootstrap.sh | sudo bash

 That does EVERY step below automatically. The manual steps are only
 if you want to do it by hand / understand it / fix one piece.


===================================================================
 MANUAL STEPS (in order)
===================================================================

STEP 1 - UPDATE UBUNTU
-------------------------------------------------------------------
    sudo apt update && sudo apt upgrade -y


STEP 2 - INSTALL POSTGRESQL
-------------------------------------------------------------------
    sudo apt install -y postgresql postgresql-contrib
    sudo systemctl enable --now postgresql


STEP 3 - CREATE DATABASE + USER
-------------------------------------------------------------------
    sudo -u postgres psql -c "CREATE ROLE jointbox LOGIN PASSWORD 'jointbox123';"
    sudo -u postgres psql -c "CREATE DATABASE jointbox OWNER jointbox;"
    sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE jointbox TO jointbox;"

    # verify:
    psql "postgresql://jointbox:jointbox123@localhost:5432/jointbox" -c "SELECT 'db ok';"


STEP 4 - (ONLY IF DB IS ACCESSED FROM ANOTHER MACHINE)
-------------------------------------------------------------------
 Skip this if the app runs on the SAME box as PostgreSQL.
 If the app (or Prisma from Windows) is on another machine:

    # allow listening on all interfaces:
    sudo sed -i "s/^#listen_addresses.*/listen_addresses = '*'/" /etc/postgresql/*/main/postgresql.conf

    # allow your LAN subnet (adjust to your network, e.g. 192.168.0.0/23):
    echo "host all all 192.168.0.0/23 scram-sha-256" | sudo tee -a /etc/postgresql/*/main/pg_hba.conf

    sudo systemctl restart postgresql


STEP 5 - INSTALL NODE 20 + TOOLS
-------------------------------------------------------------------
    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
    sudo apt install -y nodejs git build-essential
    sudo npm install -g pm2


STEP 6 - INSTALL FREERADIUS (with PostgreSQL support)
-------------------------------------------------------------------
    sudo apt install -y freeradius freeradius-postgresql freeradius-utils


STEP 7 - GET THE CODE + BACKEND .env
-------------------------------------------------------------------
    # put the project at /opt/jointbox (git clone or copy the folder), then:
    cd /opt/jointbox/backend

    cat > .env <<'ENV'
    DATABASE_URL="postgresql://jointbox:jointbox123@localhost:5432/jointbox?connection_limit=10&pool_timeout=15"
    RADIUS_DATABASE_URL="postgresql://jointbox:jointbox123@localhost:5432/jointbox"
    RADIUS_SERVER_IP="127.0.0.1"
    RADIUS_AUTH_PORT=1812
    RADIUS_ACCT_PORT=1813
    JWT_SECRET=change-this-secret
    PORT=3001
    NODE_ENV=production
    ADMIN_EMAIL="admin@jointbox.com"
    ADMIN_PASSWORD="admin123"
    ENV


STEP 8 - CREATE THE TABLES (Prisma migrations)
-------------------------------------------------------------------
 This creates ALL tables including the RADIUS tables
 (radcheck, radreply, radusergroup, radacct, radpostauth, nas).

    cd /opt/jointbox/backend
    npm install
    npx prisma generate
    npx prisma migrate deploy


STEP 9 - FREERADIUS: POINT SQL MODULE AT POSTGRES/JOINTBOX
-------------------------------------------------------------------
 The default /etc/freeradius/3.0/mods-available/sql ships with:
     dialect  = "sqlite"          <- should be postgresql
     driver   = "rlm_sql_null"    <- should be rlm_sql_postgresql
     radius_db = "radius"         <- should be jointbox
     #server   = "localhost"      <- commented out, uncomment
     #login    = "radius"         <- commented out, set to jointbox
     #password = "radpass"        <- commented out, set to jointbox123

    # a) enable the sql module
    sudo ln -sf /etc/freeradius/3.0/mods-available/sql /etc/freeradius/3.0/mods-enabled/sql

    # b) fix the six settings in one go (matches the exact default strings)
    sudo sed -i \
      -e 's/dialect = "sqlite"/dialect = "postgresql"/' \
      -e 's/driver = "rlm_sql_null"/driver = "rlm_sql_postgresql"/' \
      -e 's/#[[:space:]]*server = "localhost"/server = "localhost"/' \
      -e 's/#[[:space:]]*login = "radius"/login = "jointbox"/' \
      -e 's/#[[:space:]]*password = "radpass"/password = "jointbox123"/' \
      -e 's/radius_db = "radius"/radius_db = "jointbox"/' \
      /etc/freeradius/3.0/mods-available/sql

    # c) verify all six are now correct:
    sudo grep -nE 'dialect =|driver =|^\s*server =|^\s*login =|^\s*password =|radius_db =' /etc/freeradius/3.0/mods-available/sql


STEP 10 - FREERADIUS: ENABLE SQL IN THE DEFAULT SITE
-------------------------------------------------------------------
    # turn "-sql" into "sql" in authorize/accounting/post-auth/session
    sudo sed -i 's/^\(\s*\)-sql/\1sql/' /etc/freeradius/3.0/sites-available/default

    # fix ownership + restart
    sudo chown -h freerad:freerad /etc/freeradius/3.0/mods-enabled/sql
    sudo systemctl enable freeradius
    sudo systemctl restart freeradius

    # if it will not start, see the exact reason:
    #   sudo freeradius -X


STEP 11 - START THE APP (PM2)
-------------------------------------------------------------------
    cd /opt/jointbox/backend  && npm run build
    cd /opt/jointbox/frontend && npm install && npm run build

    pm2 start "node dist/main.js"                    --name jointbox-backend  --cwd /opt/jointbox/backend
    pm2 start "npm run start -- -p 3000 -H 0.0.0.0"  --name jointbox-frontend --cwd /opt/jointbox/frontend
    pm2 save
    pm2 startup systemd -u root --hp /root | tail -1 | sudo bash

 On first backend boot it auto-creates admin@jointbox.com / admin123.


STEP 12 - TEST RADIUS END TO END
-------------------------------------------------------------------
 1) Open the panel, create a Package (e.g. 10/10 Mbps).
 2) Create a Subscriber on it: username testuser, password test123.
    (the app writes radcheck + radreply automatically)
 3) Test:

    radtest testuser test123 127.0.0.1 0 testing123

    Expect: Access-Accept  with  Mikrotik-Rate-Limit = "10M/10M"


STEP 13 - OPEN FIREWALL PORTS (optional)
-------------------------------------------------------------------
    sudo ufw allow 22/tcp
    sudo ufw allow 80/tcp
    sudo ufw allow 3000/tcp
    sudo ufw allow 3001/tcp
    sudo ufw allow 1812/udp
    sudo ufw allow 1813/udp
    sudo ufw allow 3799/udp
    sudo ufw --force enable

 NOTES
===================================================================
 - RADIUS users can ONLY exist if the subscriber exists in the app
   (radcheck.username has a foreign key to Subscriber). Do NOT insert
   radcheck rows by hand - create the subscriber in the panel.
 - Manage the app:  pm2 status | pm2 logs | pm2 restart all
 - Update later:    cd /opt/jointbox && git pull && sudo bash deploy/install-ubuntu.sh
 - Default RADIUS client secret for local radtest is "testing123".
